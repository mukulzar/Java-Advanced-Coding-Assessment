# HTML to JSP Conversion

## Description
This practical demonstrates JavaServer Pages (JSP) and how HTML pages can be processed on the server to generate web content.

## Technologies Used
- HTML
- Java
- JSP
- Apache Tomcat
- Maven

## Requirements
- JDK
- Apache Maven
- Compatible Apache Tomcat version

## How to Run
1. Open the project folder containing `pom.xml`.
2. Build the project:
   ```bash
   mvn clean package
   ```
3. Deploy the generated WAR file to Tomcat.
4. Start Tomcat.
5. Open the application URL in your browser.

## Learning Outcome
Understand JSP processing and the integration of Java with web pages.
